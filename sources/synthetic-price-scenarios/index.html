Interpretation rules / 解釈ルール

  • Two exact observations may form a range only when currency, basis, and configuration match.
    通貨・価格の種類・構成が同じで、金額が確定した2件だけを価格幅として扱います。
  • A single observation remains a reference value, not a range.
    価格記録が1件だけの場合は、価格幅ではなく1つの参考値として扱います。
  • A starting-at value has no implied upper bound.
    最低価格だけが示されている場合、上限は推測しません。
